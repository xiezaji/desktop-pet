## 05 作品介绍（≥30 字，限 2000 字）

> **Q Pet 是一款跑在浏览器里的桌面宠物。**
>
> **使用场景**
> 开着窗口写代码时，让一个小角色待在页面角落；它会自己冒泡、说台词、发语音，
> 不用切出去也能感觉到「有人在陪着你」。
>
> **目标用户**
> 喜欢二次元角色、喜欢桌面宠物、想要一个不打扰但有存在感的小物的用户。
>
> **核心玩法与功能**
> - **四类动画实时切换**：待机 / 按下 / 点击 / 拖动，各组可独立开关与调速
> - **对话气泡**：三种皮肤（柔和渐变 / 漫画描边 / 椭圆对话框）、
>   170ms 弹出缩放动画、淡入淡出；文字装不下时**滚轮手动滚动**，并有一条极细滚动条
>   提示「还有内容、现在读到哪」
> - **语音台词**：点击随机抽一句并播放角色语音，可切换「随机 / 顺序」两种模式，音量可调
> - **角色包**：4 套内置角色，可导入自己的角色包（上传 zip 即可，
>   用浏览器原生 DecompressionStream 解压，存 IndexedDB）
> - **设置中心**：气泡外观 / 角色 / 动画 / 语音 / 通用 / 统计 六个页签，
>   主题色可换、气泡颜色有完整色板
> - **本地行为统计**：陪伴时长、互动次数、台词触发、角色使用分布
>
> **技术实现**
> 原生 JavaScript + Canvas 2D + Web Audio API，**零框架、零构建步骤**，纯静态站点。
> 桌面版资源是裸 BGRA 像素（139 MB），用工具链转成逐帧 WebP + MP3 后
> **压到 5.2 MB（27 倍）**，加载无感知。
>
> **体验方式**
> 打开链接即用，无需注册、无需下载。所有数据只存在浏览器本地，不联网、不上传。
>
> **已知限制（如实说明）**
> 浏览器沙箱内拿不到系统级数据，因此统计范围是页面内行为，
> 而非桌面版的系统级按键与软件使用；开机自启、全局热键、桌面置顶这类
> 依赖操作系统能力的功能在网页版中不可用，已从设置中移除。
